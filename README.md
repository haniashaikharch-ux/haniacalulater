# Hania's Scientific Calculator 🔬

An advanced, high-precision scientific calculator web application featuring:
- **Title & Branding:** Dedicated badge plate for **Hania's Scientific Calculator**.
- **Chassis Body:** Sleek obsidian black finish with brushed metallic bevels and tactile hardware detailing.
- **Keypad Styling:** Vibrant electric, sapphire, and cobalt blue keys with responsive 3D click feedback.
- **Display & Canvas:** Crisp high-contrast white screen and background canvas.
- **Night Vision Mode (NVG):** Tactical phosphor-green HUD overlay with authentic scanlines, glowing reticles, and sci-fi audio feedback.

---

## 🌟 Key Features

1. **Full Scientific Engine:**
   - **Trigonometry:** `sin`, `cos`, `tan`, `sin⁻¹`, `cos⁻¹`, `tan⁻¹`
   - **Hyperbolics:** `sinh`, `cosh`, `tanh`
   - **Logarithms & Powers:** `ln`, `log₁₀`, `eˣ`, `10ˣ`, `x²`, `x³`, `xʸ`, `√x`, `³√x`
   - **Combinatorics:** Factorial `x!`, reciprocal `1/x`, percentage `%`
   - **Constants:** `π` (Pi), `e` (Euler's number)
   - **Parentheses:** Nested brackets support with standard operator precedence.
   - **Angle Modes:** Quick toggle between **DEG** (Degrees) and **RAD** (Radians).

2. **Night Vision Mode:**
   - Dedicated **NIGHT VISION** toggle switch on the upper console.
   - Transitions into a tactical green-phosphor HUD with CRT scanline simulation and corner targeting reticles.

3. **Memory Storage:**
   - `MC` (Clear), `MR` (Recall), `M+` (Add to Memory).
   - Dynamic `M` indicator flag on the status display bar.

4. **Calculation History Reel:**
   - Collapsible slide-out drawer storing past calculations.
   - Single-click insertion of past answers back into the current calculation.
   - LocalStorage persistence between browser sessions.

5. **Audio Feedback (Synthesizer):**
   - Built-in zero-dependency Web Audio API synthesizer generating tactical clicks, calculation chime, and night-vision hum.
   - Mute/unmute toggle.

6. **Full Keyboard Support:**
   - Numbers `0-9`, `.`, operators `+`, `-`, `*`, `/`, `^`, `%`, parentheses `(`, `)`.
   - `Enter` or `=` to calculate, `Backspace` to delete, `Esc` to Clear All.

---

## 🚀 How to Run

Simply open `index.html` in any modern web browser (Google Chrome, Microsoft Edge, Firefox, Safari).
No installation or server setup is required.
